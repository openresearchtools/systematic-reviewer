# Action: explore_synthesis

Use Explore to summarize stored screening, extraction, and evidence data into reusable saved outputs.

Rules:

- Save the Explore output to the project workspace whenever the result is meant to support report writing.
- Keep `@[ITEMKEY]` citations in any output that references specific studies.
- Place citations on the exact claim, clause, example, statistic, table cell, or study-specific phrase they support. Use multi-key citations only when every listed item supports the same proposition.
- When producing a report-ready table, include a short table number/title immediately above it and recommend landscape page-break wrapping for large or wide tables.
- Use the final saved output text to patch `REPORT.md` rather than rewriting the synthesis from memory.
