# Action: extraction_template

Use this action family to bootstrap, inspect, save, import, or adapt extraction templates.

Recommended systematic-review template set:

- `General`
- `Interventions`
- `Summarization`

Rules:

- Start from the project-local bundled template pack that was seeded when the project was created.
- Eligibility templates should be broad enough not to over-exclude because a title/abstract or full text is underspecified.
- Prefer explicit yes/no-or-null criteria fields plus a separate free-text reason field.
- Save templates into the project template workspace so later runs and appendices can reference them.
