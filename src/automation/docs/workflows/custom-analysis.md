# Custom Analysis Workflow

Use this workflow when the project is a custom analysis rather than a systematic review.

Normal stage order:

1. Scope selection
2. Embeddings or semantic search
3. Extraction or targeted exploration
4. Report writing or exports

Rules:

- Harvest is normally disabled for custom analysis projects.
- The main collection may be a valid working scope, but all actions must remain inside the current project tree.
- Do not invent include or exclude lifecycle moves unless the user explicitly created those scopes and asked for that workflow.
- Prefer direct evidence retrieval, extraction, and report drafting over review-state transitions.
