2. Zotero citation and bibliography functions

Zotero documentation states that Zotero uses Citation Style Language (CSL) styles and the citeproc-js CSL processor for creating citations and bibliographies.

Systematic Reviewer uses those capabilities through the installed Zotero runtime for citation preview, bibliography rendering, citation text generation, style selection, locale-sensitive rendering, and CSL JSON item conversion.

Upstream references:
https://www.zotero.org/support/dev/citation_styles
https://www.zotero.org/support/dev/source_code
https://citationstyles.org/

Packaging status:
This repository does not provide a separate runtime copy of citeproc-js, CSL styles, or CSL locale files. Those capabilities are consumed from the installed Zotero runtime.

3. Zotero-compatible editable citation document conventions

Systematic Reviewer's linked-citation DOCX export intentionally writes document structures designed to interoperate with Zotero-managed editable citation workflows. This includes Zotero-style bookmark naming, custom document properties, citation field payloads, bibliography field payloads, and CSL citation metadata references to `https://github.com/citation-style-language/schema/raw/master/csl-citation.json`.

This notices entry describes compatibility conventions and Zotero-hosted runtime behavior used by the plugin. Some user-facing workflow patterns and document behaviors in Systematic Reviewer are intentionally close to native Zotero behavior so that the plugin works naturally inside Zotero and remains compatible with Zotero-managed citation editing workflows.

Systematic Reviewer remains separate independent software and is not affiliated with, sponsored by, or endorsed by the Corporation for Digital Scholarship, Microsoft, The Document Foundation, or any other project referenced in this notices file.

Notice:
Ecma International describes ECMA-376 as defining Office Open XML vocabularies, document representation, and packaging requirements, and identifies ISO/IEC 29500 as the related international standard.
Microsoft's Open Specification Promise lists Office Open XML 1.0 - Ecma-376 and Office Open XML ISO/IEC 29500 editions as covered specifications.
Microsoft's Open Specification Promise FAQ states that implementers do not need to sign anything and do not need to make any mention of or reference to Microsoft in order to implement covered specifications.
Patent-related coverage under the Open Specification Promise is separate from copyright in the standards documents themselves.

Packaging status:
This repository does not redistribute the ECMA-376 or ISO/IEC 29500 standards texts, and does not redistribute Microsoft Office code. This notice is included for standards and interoperability transparency.
